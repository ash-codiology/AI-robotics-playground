# Physical AI & Humanoid Robotics Course Book

This is the README for the Physical AI & Humanoid Robotics Textbook.

## Getting Started

1.  **Install Dependencies:**
    ```bash
    npm install
    ```
2.  **Run Locally:**
    ```bash
    npm start
    ```
    This will open a new browser window with your local Docusaurus site.

## Hero Background Image

For the homepage hero section, you can add a background image. Place your desired image (e.g., `hero-background.jpeg`) in `book/static/img/`. The `book/src/pages/index.module.css` file is configured to use `url('/img/hero-background.jpeg')` for the hero background.
